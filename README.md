#### My Motivation (Mi Motivación) ####

Una aplicación sencilla para Android que muestra frases motivadoras aleatorias y permite a los usuarios guardar sus frases favoritas.

##  Características

+ Muestra frases motivadoras aleatorias.
+ Marca frases como favoritas.
+ Visualiza todas las frases favoritas guardadas.
+ Interfaz sencilla e intuitiva.
+ Aplicación para Android desarrollada con Kotlin.

##  Tecnologías

* **Lenguaje:** Kotlin
* **IDE:** Android Studio
* **Interfaz de usuario:** Diseños XML (Layouts)
* **Plataforma:** Android

##  Primeros pasos

1. Clona este repositorio.
2. Abre el proyecto en Android Studio.
3. Espera a que Gradle termine de sincronizarse.
4. Ejecuta la aplicación en un emulador de Android o en un dispositivo compatible.

##  Notas

Las frases favoritas se almacenan en memoria durante la sesión actual de la aplicación. No se guardan de forma permanente, por lo que se pierden al finalizar el proceso de la aplicación.
